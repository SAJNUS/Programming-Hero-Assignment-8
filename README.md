# SunCart – Summer Essentials Store

An initial Next.js App Router scaffold for a summer-themed eCommerce assignment.

## Included

- Next.js App Router structure
- Tailwind CSS + DaisyUI theme setup
- Shared persistent layout
- Responsive `Navbar` and `Footer` components
- Starter routes for Home, Products, My Profile, Login, Register, and Privacy Policy

## Notes

- Authentication logic is intentionally not implemented yet.
- Backend and product APIs are intentionally not added yet.
- The layout and routes are ready for future expansion.
